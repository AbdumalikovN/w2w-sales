# Продажи W2W

Дашборд отдела продаж Win to Win: воронка, сделки на сегодня, что работает в переписке, отрасли и регионы, база курса без касания.
Страница открывается по паролю. Данные клиентов лежат в репозитории только в зашифрованном виде (AES-256-GCM, ключ из пароля через PBKDF2).

## Как обновляются данные

| Время (Ташкент) | Что происходит | Кто делает |
|---|---|---|
| 18:12 | Переписка @ceo_w2w в Telegram → карточки в Notion CRM: новые лиды, статусы, история, следующий шаг | Запланированная задача Claude (нужен включённый компьютер с приложением Claude) |
| ~19:00 | Notion CRM → шифрование → публикация страницы | GitHub Actions, workflow «Обновить дашборд» |

Ручные правки в Notion тоже попадают в дашборд при следующем запуске. Обновить сразу: вкладка **Actions** → «Обновить дашборд» → **Run workflow**.

## Настройка (один раз)

1. **Включить Pages.** Settings → Pages → Source: **GitHub Actions**.
2. **Токен Notion.**
   - Откройте https://www.notion.so/profile/integrations → **New integration** → тип *Internal*, название «W2W дашборд», рабочее пространство Win To Win. Права: только *Read content*.
   - Скопируйте *Internal Integration Secret*.
   - В Notion откройте базу **CRM** (Sales → CRM) → `···` → **Connections** → добавьте «W2W дашборд».
3. **Секреты репозитория.** Settings → Secrets and variables → Actions → **New repository secret**:
   - `NOTION_TOKEN` — секрет интеграции из шага 2;
   - `DASHBOARD_PASSWORD` — пароль страницы (тот, что выдал Claude, иначе база анкет курса не расшифруется).
4. Actions → «Обновить дашборд» → **Run workflow**. Через 1–2 минуты страница обновится.

Пока `NOTION_TOKEN` не задан, сайт публикует последний снимок `data/crm.json`.

## Поля CRM, которые читает дашборд

`Статус`, `Первое касание`, `Последнее касание`, `Встреча`, `Встреча проведена`, `Ждёт нашего ответа`, `Следующий шаг`,
`Источник`, `Отрасль`, `Регион`, `Формат касания`, `Должность контакта`, `Причина отказа`, `Запросы`, `Сумма договора`, `Telegram ID`, `Телеграм`.
Карточки без `Первое касание` не входят в воронку, но видны в реестре.

## Структура

```
index.html            страница (вход по паролю + дашборд)
assets/app.css        стиль W2W: Onest, бирюза, стекло, ауры
assets/app.js         расшифровка и расчёт аналитики в браузере
assets/fonts, img     шрифт Onest (OFL) и логотипы W2W
data/crm.json         зашифрованный снимок CRM (запасной вариант)
data/base.json        зашифрованная база анкет курса «ISAEV Dastur 24»
scripts/build.py      Notion → шифрование → _site/
.github/workflows/    расписание и публикация на GitHub Pages
```

## Смена пароля

Новый пароль нужно поставить в секрет `DASHBOARD_PASSWORD` и перешифровать базу анкет:
`DASHBOARD_PASSWORD=<новый> python scripts/build.py --encrypt-base base.json` (исходный `base.json` есть у Claude и в таблице анкет).
После этого запустите workflow. Сохранённый пароль на устройствах сбросится — войдите заново.

## Локальная проверка

```
pip install cryptography
DASHBOARD_PASSWORD=... NOTION_TOKEN=... python scripts/build.py
python -m http.server -d _site 8000
```
